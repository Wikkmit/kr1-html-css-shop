# kr1-html-css-shop

Учебный многостраничный HTML/CSS-сайт интернет-магазина.

## Контрольная работа №1

Тема: «HTML и CSS: разработка многостраничного сайта».

В проекте реализован многостраничный HTML/CSS-сайт интернет-магазина или каталога услуг.

## Ссылка на опубликованный проект

GitHub Pages: https://username.github.io/kr1-html-css-shop/

## Структура проекта

- `index.html` – главная страница;
- `catalog.html` – каталог товаров;
- `product.html` – карточка товара;
- `order.html` – страница оформления заявки;
- `contacts.html` – контактная информация;
- `css/style.css` – файл стилей;
- `js/main.js` – файл JavaScript;
- `images/` – папка для изображений;
- `sitemap.xml` – простая карта сайта;
- `README.md` – описание проекта;
- `.gitignore` – список файлов, исключённых из Git.

## Используемые технологии

- HTML;
- CSS;
- JavaScript;
- Git;
- GitHub;
- GitHub Pages.

## Реализованные элементы

- семантическая HTML-разметка;
- единая навигация между страницами;
- якорные ссылки;
- хлебные крошки;
- карточки товаров с бейджами;
- таблица характеристик;
- форма заявки;
- модальное окно;
- CSS-переменные;
- состояния `:hover`, `:focus-visible`, `:disabled`;
- Flexbox и CSS Grid;
- БЭМ-именование классов;
- позиционирование `relative`, `absolute`, `sticky`, `fixed`;
- кнопка «Наверх».
